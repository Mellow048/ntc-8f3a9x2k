## Geometry, as built

Patch is a rectangle x −5.2…5.2, z −2.4…13.6; ridges run along **x** every 1.3 m, so a lens
looking down +x sees the rows converge. Cabin at (−9, 2.6) with the door on its +x wall, gable
facing the patch. Boundary fence at x = 5.8 with the bottom rail sprung between z = 6.1 and 7.7
(the pig's crossing). Shore starts at x = 8, water at y = −6. The warship rides at (74, −6, 6.4),
bow to the lens — visible through the fence gap in shot 2.

## How to iterate

Full renders are slow and pointless until the sets exist; render stills instead:

```bash
gh workflow run render-short.yml --ref <branch> \
  -f composition=PigWarShort -f stills_only=true -f still_frame="30,110,2050"
```

Stills land in `shoots/pig-war/stills/` (the workflow commits them to the branch — Actions
artifacts are on blob storage, which this build environment cannot download from). They are
overwritten on the next run and should be deleted from git before the final delivery.
